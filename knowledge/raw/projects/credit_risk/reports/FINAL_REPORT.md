Numbers from `reports/final_metrics.json` unless noted. All figures in this report

# Executive Summary

This case study estimates borrower default risk and translates it into portfolio
expected loss using `EL = PD × LGD × EAD`. On **466,285** Lending Club
accounts with **$6.66B** decision-time exposure, portfolio
expected loss is **≈ $771.6M** (**11.6%**
EL rate). An isotonic-calibrated logistic PD achieves OOT AUC **0.669**.
Mild/severe sensitivity scenarios raise EL by **39.3%** /
**103.3%**. Monte Carlo confirms analytical EL; correlation
fattens tails. Approval thresholds show volume–risk tradeoffs without claiming an optimum.

# Business Problem

Lenders need PD (likelihood), LGD (severity), EAD (size), and portfolio aggregation —
not classification metrics alone.

# Data

Lending Club 2007–2014 (`loan_data_2007_2014.csv`). Temporal split: train ≤2012
(95,902), valid 2013 (134,755),
OOT 2014 (235,628).

# Data Quality & Leakage

DuckDB checks in `sql/01_data_quality.sql`. Underwriting PD excludes recoveries,
payments, out_prncp, loan_status, and related fields (`docs/DATA_DICTIONARY.md`).

# PD Modeling

Logistic vs HistGradientBoosting; logistic selected. Features: origination categoricals
(banded) + numerics (`src/credit_risk/features/engineering.py`).

# Calibration & Validation

Isotonic on 2013 validation. OOT: AUC 0.6689 (CI 0.6650–0.6722);
KS 0.2449; Brier raw 0.2421 → selected 0.0755.
2014 seasoning lowers observed default rate vs mean PD — documented limitation.

# LGD

Empirical on defaults: mean 0.938, median 1.000
(n=50,965). Grade means for non-defaults. Undiscounted.

# EAD

Decision-time approximation: `funded_amnt` (total $6.66B).
Realized proxy for LGD: `max(funded − principal repaid, 0)`.

# Expected Loss

Full book: EL $771.6M; wtd PD 12.35%;
wtd LGD 93.83%. OOT EL $401.9M.

# Portfolio Analysis

Grade C share of EL ≈ 28.1% vs exposure
26.7%. Grade A: exposure 15.0%,
EL 5.3%. Debt consolidation dominates purpose EL share
(see metrics segments).

# Stress Testing

Sensitivity scenarios (not regulatory): baseline $771.6M;
mild $1.08B; severe $1.57B.

# Portfolio Loss Simulation

Independent (2000 sims): mean $771.6M ≈ analytical
$771.6M (rel 0.0024%);
VaR95 $777.3M; ES95 $778.7M.
Correlated ρ=0.12 subsample VaR95 $85.4M vs independent
$42.7M.

# Risk Appetite Analysis

OOT approve if PD≤t. t=0.10 → approval 41.1%, EL rate 5.7%;
t=0.20 → 87.6% / 9.9%. No optimal cutoff.

# Recommendations

1. Monitor calibration for EL usability.
2. Track EL share by grade/purpose, not only PD.
3. Use threshold curves with governance.
4. Keep transparent PD/LGD stress knobs.
5. Improve recovery data before rich LGD models.

# Limitations

Status proxy; seasoning; LGD/EAD approximations; sensitivity stress; simplified correlation;
not Basel/IFRS9/CECL; not production underwriting.

# Next Steps

Recovery timelines, macro PD, vintage monitoring, drift detection — with live data.
